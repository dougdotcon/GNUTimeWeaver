# G2-L0 layout observation

Record register/save hook identities, device, dtype, shape, stride, offset, element size, numel, contiguity, storage relationships, attention metadata fields, request IDs, slot mapping, block table, backend, KV specs and scheduler step. Memory addresses are diagnostic only. `prefer_cross_layer_blocks=false`; if physical block dimension cannot be proven, emit `G2_BLOCK_SLICE_LAYOUT_UNRESOLVED` and do not persist.
