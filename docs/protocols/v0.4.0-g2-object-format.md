# G2 object and manifest format

Object magic/version: `timeweaver-vllm-kv-object/1`. Canonical identity header contains protocol/runtime/model/tokenizer/layout fingerprints, attention backend, layer, cache group, logical and parent hashes, token-ID hash, block size, dtype, shape/stride, payload length, endianness and serialization method. PID, address, physical block ID, time, run ID and path are excluded. `payload_sha256=SHA256(raw bytes)` and `object_sha256=SHA256(canonical_header || raw bytes)`. Store at `kv4/objects/sha256/ab/cd/<object_sha256>.twkv`.

Manifest: `timeweaver-vllm-kv-block-manifest/1`; it lists every expected layer/object, fingerprints, completeness and checksum. A manifest is complete only after every object is fsynced, reopened and validated.
