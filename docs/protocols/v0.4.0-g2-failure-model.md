# G2 failure model

Fail closed on unresolved mapping/layout, unexpected shape/stride/dtype/layer/slice, short write, disk/fsync/rename/checksum errors, corrupt existing objects, incomplete manifests, duplicate saves with inconsistent headers, pending-save shutdown timeout, staging recovery ambiguity, load/restore attempts (`G2_LOAD_PATH_NOT_AUTHORIZED`), and external matching. Queue limits produce `G2_SAVE_BACKPRESSURE_LIMIT`; no payload is silently discarded or published complete before transactional commit.
